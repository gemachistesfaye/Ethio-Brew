# ☕ Ethio-Brew: Production-Grade Coffee E-commerce

Ethio-Brew is a full-stack, multilingual e-commerce platform dedicated to the Ethiopian coffee marketplace. It features a modern React frontend, a modular Node.js backend, and a robust SQL database.

## 🎨 Key Features
- **Multilingual Support**: English, Amharic, and Afaan Oromoo.
- **Admin Dashboard**: Real-time sales charts, product CRUD, and order lifecycle management.
- **Payment Verification**: Manual transfer verification system (Telebirr/CBE).
- **AI Enhancements**: Coffee recommendation engine and Chat assistant.

## 🛠️ Technology Stack
- **Frontend**: React.js, Tailwind CSS, Lucide Icons, Chart.js, i18next.
- **Backend**: Node.js, Express, MySQL, JWT, Bcrypt.
- **Database**: MySQL/MariaDB.
